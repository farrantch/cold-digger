# Changelog

All notable changes to Cold Digger will be documented here. The project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

## [0.1.0] - 2026-09-26

### Added

- Read-only raw disk-image scanning with MBR, EBR, and GPT discovery.
- Crypto candidate detection, validation, public-address derivation, and explicit balance checks.
- Sleuth Kit filesystem inventory and recovery plus PhotoRec carving.
- Chromium, Firefox, and Internet Explorer history extraction.
- Searchable offline reports, file explorer, media gallery, and local on-demand browsing.
- Resumable scans, source identity checks, Docker isolation, and synthetic integration fixtures.
